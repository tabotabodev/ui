Tabotabo UI

One look for every app, from a single hue. Tabotabo UI is a design system for Compose Multiplatform: type, one color and calm spacing carry the design, so apps on Android, iOS, desktop and the web feel like one family.

Install it from Maven Central as io.github.tabotabodev:tabotabo-ui, then explore the live showcase, the API reference and the source on GitHub.
